# Auto Research & PDF Generator — Agentic AI

Agentic AI tool for automated research and PDF report generation with a data collection UI.

## Tech Stack

- **Backend:** Node.js, Express
- **Frontend:** Client-side UI for data collection
- **AI:** Agentic architecture with multiple specialized agents
- **Deployment:** Vercel

## Getting Started

```bash
cp .env.example .env
npm install
node server.js
```
